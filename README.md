# X-Gates Win

Клиент Xray для **Windows 10/11 (x64)**. Поднимает на компьютере **локальный SOCKS5/HTTP-прокси** и ведёт
трафик через серверы из ваших подписок (`vless` / `vmess` / `trojan` / `shadowsocks`), сам выбирая
самый быстрый рабочий сервер.

> Бета, в разработке: готовых выпусков пока нет. Своих серверов приложение не даёт — нужна ваша подписка
> (URL, ссылки текстом, base64-список или файл).

## Чем это не VPN

- **Системный прокси Windows не меняется**, драйверы и TUN не ставятся. Через прокси идут только программы,
  которые вы на него настроили (браузер, Telegram); остальной трафик идёт как раньше.
- Уживается с другим VPN на этом же компьютере.
- Установка **без прав администратора**.

## Как работает

- Ядро **Xray-core** слушает только на `127.0.0.1`:
  - **SOCKS5** — порт `10815`;
  - **HTTP** — порт `10816` (оба порта меняются в настройках).
- Кнопка **«Самый быстрый»**: пинг всех серверов → замер скорости живых → подключение к лучшему.
- **Автомониторинг** проверяет связь и при падении сервера сам переключается на другой. От сети (ноутбук на
  зарядке) проверка идёт каждые 10 секунд, и переключение занимает около полуминуты; на батарее — реже, чтобы
  беречь заряд (интервал задаётся в настройках).

## Установка

Когда выйдет первый выпуск, скачайте MSI-файл со страницы
[**Releases**](https://github.com/pico-soft/X-Gates-Win/releases/latest) и запустите. Программа ставится в
`%LOCALAPPDATA%\Programs\X-Gates Win`, ярлык — в меню «Пуск».

Установщик пока без цифровой подписи, поэтому при первом запуске Windows покажет окно «Windows защитила ваш
компьютер» → нажмите **«Подробнее» → «Выполнить в любом случае»**. Если в Windows 11 включён «Интеллектуальный
контроль приложений» (Smart App Control), неподписанную программу он не пропустит.

## Первый запуск

1. Вкладка **«Подписки»** → добавьте URL подписки, вставьте ссылки текстом (`vless:// vmess:// trojan:// ss://`
   или base64) либо **«Импорт из файла…»**.
2. Вкладка **«Главная»** → **«▶ Самый быстрый»**.
3. Настройте браузер (ниже) и проверьте: откройте [2ip.ru](https://2ip.ru) — адрес и страна должны быть
   зарубежными.

## Настройка программ

- **Firefox** — кнопка **«Настроить Firefox»** в настройках приложения (снять — «Вернуть как было», при закрытом
  Firefox). Вручную: Настройки → Основные → Параметры сети → «Настроить…» → «Ручная настройка прокси» → узел SOCKS `127.0.0.1`,
  порт `10815`, SOCKS 5, отметить «Отправлять DNS-запросы через прокси при использовании SOCKS 5».
- **Chrome / Edge** берут только системный прокси, а X-Gates Win его не меняет. Варианты: расширение-переключатель
  прокси (SOCKS5 `127.0.0.1:10815`) или отдельный ярлык браузера с параметром
  `--proxy-server="socks5://127.0.0.1:10815"` (перед запуском такого ярлыка закройте все окна браузера).
- **Telegram Desktop** — Настройки → Продвинутые настройки → Тип соединения → «Использовать собственный прокси» →
  SOCKS5, сервер `127.0.0.1`, порт `10815`, логин и пароль пустые.
- Программы с HTTP-прокси — `127.0.0.1:10816`.

Тот же текст с вашими текущими портами есть в приложении: **Настройки → «Как подключить браузер и Telegram»**.

## Возможности

- Несколько подписок; если прямой доступ к источнику подписки заблокирован, загрузка идёт обходными путями
  (в том числе через уже работающий сервер).
- Тест скорости, автоподключение к быстрейшему серверу, автомониторинг с переключением.
- Дробление начала TLS-соединения — по желанию, в настройках: помогает, когда блокируют по имени сайта.
- **Стоп-лист**: скрыть серверы по слову в имени или по одному; «Не использовать» для отдельного сервера.
- Учёт трафика по дням.
- Запуск при входе в Windows (в трее, с последним сервером) — по желанию, в настройках.
- Встроенные обновления с GitHub: подпись манифеста обновления (ECDSA P-256) и SHA-256 установщика проверяются
  до установки.
- Отчёты о сбоях хранятся на компьютере и отправляются разработчику только по вашему решению.
- Данные (подписки, настройки, стоп-лист, трафик) — в `%LOCALAPPDATA%\X-Gates`.

## Сборка из исходников

Нужен **.NET 10 SDK**. Программа собирается и на Linux (`EnableWindowsTargeting` уже включён).

```bash
tools/xray/fetch-xray.sh                       # ядро Xray-core v26.7.28 с проверкой SHA-256 → third_party/xray/
dotnet test tests/XGates.Core.Tests            # тесты (часть из них поднимает настоящее ядро xray)
dotnet publish src/XGates.Win -c Release -r win-x64 --self-contained   # программа для Windows x64
```

Установщик MSI собирается на Windows инструментом WiX Toolset v5 (сборка в GitHub Actions готовится).

## Структура репозитория

- `src/XGates.Core` — логика: подписки, конфиг Xray, тесты скорости, монитор, обновления.
- `src/XGates.App` — модели экранов; `src/XGates.Win` — оконное приложение (WPF).
- `tests/` — тесты; `tools/` — скрипты: ядро, выпуск обновлений, сверочные тесты.
- `app/` — эталонная реализация той же логики на Kotlin. Сверочные тесты (`tools/golden`) проверяют, что ядро на
  C# ведёт себя в точности так же. В программу этот код не входит.
- `docs/`, `CLAUDE.md`, `HANDOFF.md`, `UPSTREAM-SYNC.md` — рабочие заметки разработки.
